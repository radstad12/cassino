# Neon Noir Poker

A cinematic 5-max Texas Hold'em demo built with React + TypeScript + Vite.

## GitHub Pages

This repository is configured for:

`https://radstad12.github.io/cassino/`

The GitHub Actions workflow automatically builds and deploys the app after every push to `main`.

### GitHub setup

1. Push the **contents** of this folder to the repository root (do not upload only the ZIP).
2. Open **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. Push to `main` or run the `Deploy to GitHub Pages` workflow manually.
5. Wait for the workflow to finish, then open the Pages URL.

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
