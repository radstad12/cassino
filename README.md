# Neon Noir Poker

Standalone GitHub Pages build. No Node, npm, React or GitHub Actions required.

## Deploy on GitHub Pages
1. Put `index.html` and `README.md` in the repository root.
2. GitHub → Settings → Pages.
3. Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)**.
5. Save.

The game is intentionally standalone so it works directly as a static GitHub Pages site.
